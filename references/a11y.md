## 必须满足的 baseline (W19 累计)

### 1. Skip-to-content link

`src/layouts/Layout.astro`:
```astro
<a href="#main-content" class="sr-only focus:bg-primary focus:fixed focus:left-3 focus:not-sr-only ..." id="skip-to-content">
  跳到主要内容 / Skip to main content
</a>
```

JS 让 `<main>` 接收 focus (preventScroll):
```javascript
document.getElementById('skip-to-content')?.addEventListener('click', function() {
  const t = document.getElementById('main-content');
  if (t) setTimeout(function() { t.focus({preventScroll: true}) }, 0);
});
```

**对应 `<main>`**:
```astro
<main id="main-content" tabindex="-1">
```

### 2. `prefers-reduced-motion` 全局规则

`src/assets/styles/tailwind.css`:
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

### 3. 搜索页 a11y

`src/pages/search.astro` + `src/pages/en/search.astro`:
- `<label class="sr-only">` 关联 input
- `aria-label` + `aria-describedby` on input
- `role="status" aria-live="polite"` 状态反馈
- `role="tabpanel" aria-busy` 结果区
- `<kbd>` 元素显式 `text-slate-800 dark:text-slate-100`(否则对比度不足)

### 4. Dropdown ARIA

`src/components/widgets/Header.astro`:
```astro
<button type="button" aria-expanded="false" aria-haspopup="menu">概念解读</button>
<ul role="menu">
  <li role="none"><a role="menuitem" href="...">...</a></li>
</ul>
```

JS 同步 `aria-expanded` 通过 `:hover, :focus-within`:
```javascript
e.addEventListener('mouseenter', n);
e.addEventListener('mouseleave', n);
e.addEventListener('focusin', n);
e.addEventListener('focusout', n);
// n(): e.matches(":hover, :focus-within") → set aria-expanded
```

### 5. SocialShare ARIA

`src/components/common/SocialShare.astro`:
```astro
<div role="group" aria-label="分享文章到社交媒体">
  <button type="button" aria-label="分享到 X (Twitter)" ...>...</button>
  ...
</div>
```

**关键**:5 个 share 按钮必须 `type="button"`,否则默认 `type="submit"` 会触发 form submit。

### 6. Copy code button + live region

`<pre>` 复制按钮:
```html
<button type="button" aria-label="复制代码到剪贴板">
  <svg aria-hidden="true">...</svg>
  <span>Copy</span>
  <span class="sr-only" role="status" aria-live="polite"></span>
</button>
```

Live region 在 copy 成功时填 `已复制代码`,失败时填 `复制失败`,1.5s 后清空。**不抢 focus**(用户已经焦点在 button 上)。

### 7. TOC + reading progress

`src/components/blog/SinglePost.astro`:
- TOC: `<nav aria-label="文章目录">`
- 当前章节:`aria-current="location"` 跟 active section 联动
- Reading progress bar:`aria-hidden="true"` (装饰性)

### 8. Article hero image alt

```astro
<Image src={post.image} alt="" ... />
```

**`alt=""` 是装饰性 alt** — 文章 hero 是 design 元素,不是内容图片,所以给空串告诉屏幕阅读器跳过。

**如果改成描述性 alt**:`alt={post.excerpt}` 或 `alt={post.title}`。W19 决定 `alt=""` 装饰性。

## 颜色对比度

| 元素 | 颜色 | 对比度 | 标准 |
|---|---|---|---|
| `--aw-color-primary` | `rgb(67 56 202)` (indigo-700) | 6.5:1 | AAA |
| `--aw-color-text-default` | `rgb(30 41 59)` (slate-800) | 12:1 | AAA |
| `--aw-color-text-muted` | `rgb(71 85 105 / 75%)` (slate-500 75%) | 4.5:1 (small text) | AA |
| `<kbd>` | `text-slate-800` / `dark:text-slate-100` | 12:1 / 15:1 | AAA |
| Code block tokens | 自定义 CSS variables | 4.5:1+ | AA |

**改主题色**:改 `src/components/CustomStyles.astro` 的 `--aw-color-primary`。**不要**改回 indigo-600 (5.5:1,只 AA)。

## Shiki 代码高亮 (AA contrast)

`astro.config.ts`:
```typescript
shikiConfig: { theme: 'css-variables', wrap: true }
```

`src/assets/styles/tailwind.css` 定义 12 个 `--astro-code-*` 变量,每个 token 满足 AA 4.5:1。

**改 token 颜色**:**只改 CSS 变量**,不要换 Shiki theme。

## 404 page landmark

`src/pages/404.astro` 用 `Layout` (不是 `PageLayout`) + 自带 `<main id="main-content" tabindex="-1">`。**不要**用 PageLayout (它有自己的 `<main>`,会嵌套 main landmark = axe 报错)。

## Announcement role="region"

`src/components/widgets/Announcement.astro`:
```astro
<div role="region" aria-label="站点公告">
  <span aria-hidden="true">NEW</span>
  <a>...</a>
</div>
```

**为什么 `role="region"`**:满足 axe `region` rule(landmarks 之一)。

## 调试清单

| axe 报错 | 修复 |
|---|---|
| `color-contrast` | 改元素颜色到 AA 4.5:1+ |
| `landmark-unique` | 不要嵌套 `<main>` (404 page 用 Layout 不是 PageLayout) |
| `aria-required-children` | 父 `role="menu"` 缺 `role="menuitem"` 子 |
| `label` | input 缺 label,加 `<label class="sr-only">` |
| `button-name` | `<button>` 缺 `aria-label` 或可见文字 |
| `link-name` | `<a>` 缺可见文字或 `aria-label` |
| `region` | 重要 banner-like 元素缺 `role="region" aria-label` |
| `image-alt` | `<img>` 缺 alt,装饰性用 `alt=""` |
| `html-has-lang` | `<html>` 缺 `lang` (zh 页 `lang="zh-CN"`,en 页 `lang="en"`) |
| `scrollable-region-focusable` | 滚动区域缺 tabindex |

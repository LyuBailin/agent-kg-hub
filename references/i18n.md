# i18n (Chinese + English)

> URL-based locale detection。`/en/...` = English, else Chinese。zh + en 文件并行,**文章本体翻译,封面/图共用**。

## URL 规则

| 模式 | 语言 |
|---|---|
| `/agent-kg-hub/concept-react-intro/` | 中文 (zh-Hans) |
| `/agent-kg-hub/en/articles/concept-react-intro/` | English |
| `/agent-kg-hub/learning-path/` | 中文 |
| `/agent-kg-hub/en/learning-path/` | English |
| `/agent-kg-hub/category/he2-xin1-gai4-nian4/` | 中文分类页 |
| `/agent-kg-hub/en/category/core-concepts/` | English 分类页 |

**Astro `base: '/agent-kg-hub'`** 加在前面,`Astro.url.pathname` 包含 base。

## Locale 检测

`src/utils/locale.ts`:

```typescript
// 关键 regex:segment-boundary 避免误匹配
export const detectLocale = (pathname: string): 'zh' | 'en' => {
  return /(^|\/)en(\/|$)/.test(pathname) ? 'en' : 'zh';
};

export const localeToBcp47 = (locale: 'zh' | 'en'): string =>
  locale === 'en' ? 'en_US' : 'zh_CN';
```

**为什么用 `/(^|\/)en(\/|$)/` 而不是 `/\/en\//`**:
- 避免 `/agent-kg-hub/english-tutorial/` 误判为 en
- 避免 `/category/something-en/` 误判
- 严格按 `/` 段边界匹配

## 文章文件映射

| zh | en |
|---|---|
| `src/data/post/concept-react-intro.md` | `src/data/post-en/concept-react-intro.md` |
| `src/data/post/resource-langgraph.md` | `src/data/post-en/resource-langgraph.md` |

**slug 命名**:
- zh 用**拼音 + 数字声调**:`he2-xin1-gai4-nian4` (核心概念), `jiao4-cheng2-bo2-ke4` (教程与博客)
- en 用 **kebab-case English**:`core-concepts`, `tutorials-and-blogs`
- 文章 slug 一致 (跨语言):`concept-react-intro` 两边都用

**cover image 命名**(见 [references/images-pipeline.md](references/images-pipeline.md)):
- `cover-{category}-{slug}.png` 跨语言共用同一张
- `cover-concept-react-intro.png` 不区分 zh/en

## 路由详情

### zh 文章页 — `src/pages/[...blog]/index.astro`

- 走 **Astro content collections** (`src/content.config.ts`)
- `getStaticPathsBlogPost()` 在 `src/utils/blog.ts`
- 文件 frontmatter 直接被 schema 验证
- `post.image` 在 frontmatter 中是 `string` (路径)

### en 文章页 — `src/pages/en/articles/[...post].astro`

- 走 **`import.meta.glob` 直接加载** `src/data/post-en/*.md`
- **不走 content collections**(因为 en files 跟 zh files 在不同目录,且 zod schema 可能不一致)
- 自己定义 `EnPostModuleData` interface
- ⚠️ **W20 bug 修复点**:metadata 构造必须传 `image` (ImageMetadata) 而非 `frontmatter.image` (raw string),详见 [references/images-pipeline.md §en 端 og:image 双 bug](references/images-pipeline.md)

### zh/en 列表页 (articles, category, tag, learning-path)

- `src/pages/[...blog]/[...page].astro` (zh, content collections 驱动)
- `src/pages/en/articles/index.astro` (en 列表,自己用 `import.meta.glob` 拼)
- `src/pages/en/category/[category]/[...page].astro` (en 分类)
- `src/pages/en/tag/[tag]/[...page].astro` (en 标签)

## 跨语言链接

从 en 页跳到中文对应页(或反向)时:
- zh 页里 anchor → en 链接: `/en/...` 绝对路径
- en 页里 anchor → zh 链接: `/...` 绝对路径
- 例子 (在 zh 页):`<a href="/agent-kg-hub/en/articles/concept-react-intro">English version</a>`
- 例子 (在 en 页):`<a href="/agent-kg-hub/concept-react-intro">中文版本</a>`

**重要 bug**(W16.2 修复):
- 早期 `/agent-kg-hub/#paradigms` anchor 在 en 页面会让 en 用户跳到**中文**首页的 `#paradigms`
- 修复:en 页面 anchor 用 `/en/#paradigms`

## 翻译流程

新增文章:
1. 在 `src/data/post/{category}-{slug}.md` 写中文版
2. 翻译整个 frontmatter + body 到 `src/data/post-en/{category}-{slug}.md`
3. **`image` 字段值保持一致**(共用同一张 cover)
4. **`tags` 数组翻译,但 slug 化的 tag 路径两边不同** (zh pinyin vs en English)
5. 跑 `npm run check` + `npm run build`,确保 en 端 200 OK

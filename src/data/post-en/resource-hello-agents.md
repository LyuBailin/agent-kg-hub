# Datawhale Hello-Agents

> The most systematic Chinese Agent onboarding tutorial, 21k+ stars.

- 🔗 Repo: <https://github.com/datawhalechina/hello-agents>
- ⭐ Stars: 21k+ (as of July 2026)
- 📜 License: CC BY-NC-SA 4.0
- 🏢 Maintainer: Datawhale Community
- 🇨🇳 Language: Chinese

## What Problem Does It Solve

Several pain points for Chinese LLM Agent learning:

1. **English-first materials** — 90% of papers, official docs, and blogs are in English
2. **Fragmentation** — Concepts scattered across blogs, Twitter, videos
3. **Lack of practice** — Lots of theory, few runnable demos
4. **Lack of systematic structure** — No complete "from zero" path

Hello-Agents tries to solve all these in one go.

## Tutorial Structure

| Chapter | Topic | Audience |
|---------|-------|----------|
| Chapter 1 | What is an Agent | Complete beginners |
| Chapter 2 | ReAct and Basic Loops | Beginners |
| Chapter 3 | Tool Use | Beginners |
| Chapter 4 | Plan-and-Execute | Intermediate |
| Chapter 5 | Memory (short-term/long-term/vector) | Intermediate |
| Chapter 6 | Multi-Agent Collaboration | Intermediate |
| Chapter 7 | Agent Evaluation | Practical |
| Chapter 8 | Agent Practical Projects | Practical |
| Chapter 9 | Frontier Directions (Graph Agents, Agentic Workflow) | Everyone |

Each chapter includes: **concept explanation + code implementation + practical demo + thought exercises**.

## Why It's Important for Agent × KG

- **Chapter 9 specifically covers Graph Agents**: GraphRAG principles, integration with Agents
- **Chapter 5 on Memory**: thoroughly covers using KG as long-term memory
- **Chinese-friendly**: All concepts, code comments, and exercises in Chinese
- **Continuously updated**: Datawhale community maintained, iterating in 2025-2026

## Who Is It For

- ✅ Chinese-native Agent beginners
- ✅ Engineers wanting to systematically review Agent knowledge
- ✅ People preparing Agent teaching/training
- ❌ Not for: senior engineers already in Agent production (content is more entry-level)

## Recommended Learning Path

1. First read chapters 1-3 (1 week)
2. Run the code demos in each chapter (read-and-run, 1-2 weeks)
3. Pick 1-2 chapters of interest to dive deep (chapters 5/6/9 optional)
4. Migrate the tutorial content to your own projects

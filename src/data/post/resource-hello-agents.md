# Datawhale Hello-Agents

> 中文社区最系统的 Agent 入门教程,21k+ stars。

- 🔗 仓库: <https://github.com/datawhalechina/hello-agents>
- ⭐ Stars: 21k+ (2026 年 7 月)
- 📜 协议: CC BY-NC-SA 4.0
- 🏢 维护: Datawhale 社区
- 🇨🇳 语言: 中文

## 它解决什么问题

中文 LLM Agent 学习的几个痛点:

1. **英文资料为主** — 论文、官方文档、博客 90% 是英文
2. **碎片化** — 概念散落在博客、推特、视频
3. **缺实战** — 讲原理多,跑通 demo 少
4. **缺体系** — 没有一个完整的"从零开始"路径

Hello-Agents 试图一站式解决。

## 教程结构

| 章节 | 主题 | 适合谁 |
|------|------|--------|
| 第 1 章 | 什么是 Agent | 完全新手 |
| 第 2 章 | ReAct 与基础循环 | 入门者 |
| 第 3 章 | 工具调用(Tool Use) | 入门者 |
| 第 4 章 | Plan-and-Execute | 进阶 |
| 第 5 章 | Memory(短期/长期/向量) | 进阶 |
| 第 6 章 | Multi-Agent 协作 | 进阶 |
| 第 7 章 | Agent 评估 | 实战 |
| 第 8 章 | Agent 实战项目 | 实战 |
| 第 9 章 | 前沿方向(图智能体、Agentic Workflow) | 所有人 |

每一章都包含:**原理讲解 + 代码实现 + 实战 demo + 思考题**。

## 为什么对 Agent × KG 重要

- **第 9 章专门讲图智能体**:覆盖 GraphRAG 原理、与 Agent 的集成方式
- **第 5 章的 Memory 部分**:把 KG 作为长期记忆的方案讲得很透
- **中文友好**:所有概念、代码注释、思考题都是中文
- **持续更新**:Datawhale 社区维护,2025-2026 还在迭代

## 适合谁

- ✅ 中文母语的 Agent 入门者
- ✅ 想要系统梳理 Agent 知识体系的工程师
- ✅ 准备做 Agent 教学/培训的人
- ❌ 不适合:已经在做 Agent 生产的资深工程师(内容偏入门)

## 推荐学习路径

1. 先读第 1-3 章(1 周)
2. 跑通每个章节的代码 demo(边读边跑,1-2 周)
3. 选 1-2 个感兴趣的章节深入(可选章节 5/6/9)
4. 把教程里的内容迁移到自己的项目里

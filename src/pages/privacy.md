# 隐私政策

最后更新:2026-07-26

本站为静态网站,所有内容均托管在 GitHub Pages 上。

## 数据收集

本站不主动收集任何用户个人数据。服务器日志由 GitHub Pages 维护,详见 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement)。

## Cookie

本站不使用任何 Cookie。

## 第三方资源

本站可能引用以下第三方资源,它们各自有独立的隐私政策:

- [GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement) — 仓库托管
- [Unsplash](https://unsplash.com/privacy) — 部分图片素材

## 联系方式

如有隐私相关问题,请通过 [GitHub Issue](https://github.com/LyuBailin/agent-kg-hub/issues) 联系。
